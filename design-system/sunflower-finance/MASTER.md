# Sunflower Finance — sistema visual

Painel diário de economia do Sunflower Land. Direção escura confirmada por Rafael em 17/11/2026.

Pesquisa UI/UX Pro Max: `analytics dashboard`, estilo Data-Dense Dashboard. A estrutura de landing page e a paleta clara retornadas não se aplicam ao produto. Adaptação: navegação persistente, resumo, tabela comparativa e formulários com divulgação progressiva.

- Fundo #101414, superfícies #181e1c / #1d2521, texto #edf2ee, secundário #a3afa8.
- Ação principal #b6ed8c com texto #172315; positivo #b6ed8c, negativo #ffaaa1, atenção #f1cd86.
- System sans para leitura; números tabulares; títulos 28–34px, conteúdo 14–16px, legendas >=12px.
- Grade de 12 colunas; sidebar 224px; conteúdo máximo 1560px. Espaçamento 4/8/12/16/24/32.
- Cards com radius 14px, limites discretos. Evitar brilho, gradientes decorativos e componentes de estilos diferentes.
- Ícones Phosphor Regular locais, 20px, ocultos de tecnologia assistiva quando decorativos.
- Movimento: Emil primário, Jakub secundário. Controles e números respondem imediatamente. Transição de opacity apenas no aviso de salvamento; reduced-motion desativa.
- Foco visível, labels explícitos, alvos de 44px, dados faltantes indicados por texto, navegação por hash, tabelas roláveis apenas no seu contêiner.

Preservar GitHub Pages e a calculadora histórica. Não adicionar framework apenas para usar uma biblioteca de componentes.
